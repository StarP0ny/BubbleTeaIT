# Компоненты

> Историческая инвентаризация на 23 октября 2026 года. Ревизии ниже
> соответствуют сабмодулям; актуальный статус продукта — в [README](../README.md).

Зафиксированы 23 октября 2026 года. Исходники находятся в `vendor/` как
настоящие Git-сабмодули с официальными upstream URL. Ревизии задаются
gitlink в родительском репозитории; обновления выполняются осознанно.

CocoIndex Code и LightRAG закреплены на ревизиях прежнего исследования;
остальные — на полученных при переносе ревизиях upstream. Это исследовательские
снимки, не выбранный комплект совместимых стабильных релизов. Лицензии
компонентов остаются в их репозиториях; корневой MIT не заменяет их условия.

Сабмодули содержат исходники, а не готовые работающие сервисы. Установка,
веса, контейнеры и хранилища подключаются только для выбранного backend.
При копировании LFS smudge отключён: LFS-объекты при необходимости получают
отдельно. Вложенные сабмодули компонентов сейчас не инициализировались.

```powershell
git submodule update --init --depth 1
git submodule status
```

Можно получить только нужный компонент:

```powershell
git submodule update --init --depth 1 vendor/cocoindex-code
```

Исследовательский runtime вынесен в локальный `attic/` и не входит в baseline.
Python-зависимости и lock-файлы baseline — в `requirements/`.

Критерий добавления компонента в рабочий профиль — измеренная польза и
поддержка источников/версий, а не наличие его checkout. Все пять сервисов
одновременно для работы BubbleTeaIT не требуются.
